# RatSteal Progression

## 목적

이 문서는 `RatSteal` 한 판의 **진행 구조, 제한 시간, 난이도, 점수 등급**을 정의한다. 코어 루프는 [01_CoreLoop.md](01_CoreLoop.md), 구체 수치는 [50_Content_Balance.md](50_Content_Balance.md)가 소유한다.

## 판 구조

```text
단일 판 (라운드 분할 없음).
- 시작: Ready(카운트다운)
- 본편: Playing (3분 카운트다운, 스코어 어택)
- 종료: 3분 경과(생존) 또는 패배(포만 0 / HP 0) → End
```

## 제한 시간 (확정)

```text
한 판 길이: 3분
타이머는 22_System_Timer가 소유.
3분 경과 시: 생존 상태면 점수/등급 산정 후 결과 화면(승리 트리거 없음 = 스코어 어택).
```

## 난이도

```text
난이도 페이즈 없음. (원작 GameState::Rage는 미구현이라 채택 안 함)
시간 경과에 따른 압박은 "포만이 계속 줄어듦"으로만 발생.
포만 감소율은 고정값 (가속 없음, 14_Hunger / 50_Balance에서 확인 완료).
초반엔 작물이 덜 자라 점수 기회가 적고, 시간이 지나며 성숙한 작물이 늘어 점수 기회 증가.
```

## 점수 등급 (신규 — 원작에 없음)

스코어 어택 동기 부여를 위해 **신규로 추가**한다.

```text
생존 종료 시 총점 구간으로 등급 표기 (예: ★ / ★★ / ★★★).
등급 컷 수치는 밸런스 후 50_Content_Balance에서 확정.
패배(포만0/HP0) 시에도 도달 점수는 표기하되 등급 컷은 별도 정책(확인 필요).
```

## 밸런스 의도

```text
초반: 작물 미성숙 → 동선/잠입 학습 구간
중반: 작물 다수 성숙 → 적재량(점수) vs 이동속도(안전) 의사결정 핵심
후반: 포만 압박 누적 → 욕심(과적·고가치)과 안전(소량 빈번 운반)의 트레이드오프
```

## 미해결 / 확인 필요

```text
- 점수 등급 컷 수치(밸런스 후)
- 패배 시 등급 표기 정책
- 카운트다운(Ready) 길이
```
