# RatSteal Core Loop

## 목적

이 문서는 `RatSteal` 한 판의 **코어 게임 루프**와 **승/패 조건**을 정의한다. 진행/시간·난이도는 [02_Progression.md](02_Progression.md), 수치는 [50_Content_Balance.md](50_Content_Balance.md)가 소유한다.

## 한 판 흐름

```text
1. 진입      본편 상호작용 오브젝트 → RatSteal 전용 레벨 로드 (31_Flow 참고)
2. 시작      타이머 시작, 밭에서 농작물이 시간에 따라 자라남 (20_System_Spawn)
3. 잠입      쥐가 Farmer 감지 반경을 피해 밭으로 접근
4. 훔치기    다 자란 작물에 닿아 Z(상호작용) → 인벤토리에 적재, 작물 제거
5. 운반      짐이 많을수록 느려짐 (무게 = 감속, 16_Inventory)
6. 제출      제출존(SubMissionArea) 진입 → 인벤토리 정산 → 점수 획득
7. 먹이기    제출 점수만큼 포만(Baby fullness) 회복 (13_Baby / 14_Hunger)
8. 반복      포만은 계속 줄어듦 → 3~7 반복
9. 종료      승/패 조건 충족 → 결과(엔딩) 화면 → 본편 복귀
```

## 핵심 긴장 구조

```text
시간 압박   포만이 초당 일정량 감소 → 가만히 있으면 패배
위험-보상   많이 들면 점수↑ 이지만 이동속도↓ → 잡힐 위험↑
스텔스      Farmer에게 보이면 추적/공격 → 부쉬에 숨으면 추적 해제
```

원작 기준 포만 감소는 2초당 20(=초당 10), 시작값 1000. 제출 시 점수만큼 포만 회복(아기를 먹임). → 정확한 수치는 [50_Content_Balance.md](50_Content_Balance.md).

## 목표 / 종료 조건 (확정)

**명시적 승리 조건은 없다.** 제한 시간 **3분** 동안 생존하며 **최대한 많은 점수**를 모으는 스코어 어택이다.

```text
목표        3분 동안 살아남아 최대 점수 획득 (하이스코어)
종료(생존)  3분 경과 → 결과 화면에서 점수/등급 표기(41_UI_Menus)
종료(패배)  BabyStarved : 포만 0 (스토리상 "아기가 배고파 끝남" — 정식 결말)
종료(패배)  PlayerDead  : HP 0 (Farmer 피격 누적)
```

- 점수 등급(별점 등)은 **원작엔 없으나 신규로 추가**한다(생존 종료 시 점수 구간별). → [02_Progression.md](02_Progression.md) / [41_UI_Menus.md](41_UI_Menus.md).
- 패배해도 그 시점까지의 점수는 기록한다(스코어 어택).

## 상태(흐름) 모델

```text
Ready    레벨 로드, 카운트다운/안내
Playing  타이머(3분)·스폰·포만 감소 진행 (코어 루프)
Paused   일시정지 (41_UI_Menus)
End      종료 사유 확정(TimeUp/BabyStarved/PlayerDead) → 결과 화면
```

원작 `GameState` enum에 `Rage` 값이 있으나 **실제 동작 구현이 없어** 채택하지 않는다(난이도 페이즈 없음).

## 구현 범위

코어 루프 전체를 1차로 만든다. (포만·은신·인벤토리 포함)

```text
포함: 이동, 훔치기, 적재-감속, 버리기, 제출, 점수, 포만/먹이기, 은신,
      타이머(3분), Farmer 순찰/추적/공격, 패배(BabyStarved/PlayerDead), 점수 등급
빌드 씬: 튜토리얼 + 메인 게임 씬 2개 (32_Tutorial / 30_Level)
```

전체가 동작하는 수직 슬라이스를 메인 씬으로 만들고, 학습용 튜토리얼 씬을 별도로 둔다.
