# RatSteal Controls

## 목적

이 문서는 `RatSteal`의 **입력 매핑과 조작 규칙**을 정의한다. UE 구현은 Enhanced Input 전용(Legacy 금지), 미니게임 전용 `IMC_RatSteal`을 사용한다. 본편 IMC와 분리한다. **게임패드 미지원(키보드 전용).**

## 입력 (원작 키 유지)

```text
이동      방향키/WASD     이동 (정규화 후 적용)
훔치기    Z              작물에 겹친 상태에서 Steal → 인벤토리 적재 + 작물 제거
슬롯 변경 X              현재 슬롯 전환 (0→1→2→0)
버리기    C              현재 슬롯 1개 버림 (도주용 — 아래)
```

원작 디버그 키(B=Hit, N=즉사, Q/W/E=아이템 강제추가, A=무게로그)는 이식하지 않는다.

## UE 입력 매핑 (IMC_RatSteal)

```text
IA_Rat_Move      Axis2D   WASD/방향키     이동
IA_Rat_Steal     Bool     Z              훔치기
IA_Rat_SlotNext  Bool     X              슬롯 전환 (2차, 16_Inventory)
IA_Rat_Throw     Bool     C              버리기 (2차, 16_Inventory)
IA_Rat_Pause     Bool     Esc            일시정지 (41_UI_Menus)
```

1차는 Move + Steal + Pause. 슬롯/버리기는 인벤토리 도입(2차) 시 활성화.

## 조작 규칙

```text
이동
- 입력 벡터 정규화 후 속도 적용.
- 이동속도 = max(기본500 / SpeedMultiplier, 최소50). SpeedMultiplier는 적재 아이템
  개수 지수식(16_Inventory). 많이 들수록 느려짐.

훔치기 (Steal)
- 작물 콜라이더와 겹친 상태에서 Z → 종류/크기를 인벤토리에 적재 후 작물 제거.
- 다 자란(S 이상) 작물만 가능(12_Entity_Crop).
- 크기가 클수록 슬롯 카운트가 더 많이 쌓임(S+1 / M+6 / L+9) → 점수·감속에 반영.

슬롯 전환 (X)
- 현재 활성 슬롯을 0→1→2→0으로 순환.

버리기 (C) — 도주 가속
- 현재 슬롯 카운트 1 감소.
- 적재가 줄어 SpeedMultiplier가 즉시 하락 → 이동속도 즉시 상승.
- 추격당할 때 짐을 버려 순간적으로 빨라지는 도주 수단(점수 손실과 트레이드오프).

상호작용 우선순위
- 동시에 여러 작물과 겹치면 가장 가까운 1개를 대상으로 한다(UE에서 거리 기준 명확화).
```

## 입력 잠금 / 상태

```text
사망/결과 화면: 이동·훔치기 입력 차단.
일시정지 중: 메뉴 입력만 허용.
피격 무적 시간 중에도 이동·조작은 정상(무적은 피해만 무시, 10_Player).
```

## 미해결 / 확인 필요

```text
- 훔치기와 슬롯/버리기 키를 1차부터 모두 노출할지(인벤토리 도입 시점)
```
