# RatSteal Content / Balance (밸런스 수치표)

> 이 문서는 원작 기준 수치와 C++ `UPROPERTY` 기본값/에디터 조정값의 근거를 정리한다. 실제 구현 수치는 코드 기본값과 에디터 설정을 따른다.
> **원칙: 모든 수치는 원작 D2DGame을 그대로 따른다.**

## 인벤토리 / 감속 (16_Inventory) — 원작 실제 적용식

```text
슬롯 수            3 (maxSlotNum=2)

[실제 이동에 적용되는 식]
SpeedMultiplier = (1.01)^감자카운트 × (1.02)^가지카운트 × (1.03)^호박카운트
이동속도        = max(500 / SpeedMultiplier, 50)
1카운트당 감속    감자 1% / 가지 2% / 호박 3% (복리)

버리기(C)         현재 슬롯 카운트 -1 → SpeedMultiplier 즉시↓ → 속도 즉시↑ (도주)

[원작 미사용 — 이식 제외]
GetWeight 구간계수  count/3: 0→1.0, 1→0.9, 2→0.8, 3+→0.7 (× 기본무게 25/10/50)
weightDivisor 300   weightMult=1+weight/300 은 계산만 하고 이동에 미사용(죽은 코드)
```

## 미확정 수치 목록

```text
- 점수 등급(★) 컷 수치 (신규 — 밸런스 후)
- 밭별 maxRate / spawnTime (원작 초기화부 추가 확인)
- 랭크별 작물 종류 확률(RandomCrop 인자)
- 버리기 쿨다운(throwTime) 값
```

## 구현 단계에서 조정 (수치 보면서)

```text
- 픽셀 → UE 월드 단위 환산: 원작 엔진 단위가 비표준일 수 있어 고정 계수로 못 박지 않고
  실제 플레이로 조정한다(맵 크기/카메라 줌/속도 감각을 함께 본다).
- 피격 무적: 원작 15프레임 기준 → 초 변환을 플레이로 미세조정.
- 위 둘은 "원작 값 유지" 원칙의 예외가 아니라, 단위/프레임 의존 값이라 환산만 조정.
```
