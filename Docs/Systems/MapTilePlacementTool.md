# 맵 타일 배치 툴

## 목적과 범위

맵 타일 배치 툴은 에디터 전용 도킹 탭이다. 현재 레벨의 정사각형 바닥 타일 배치를 2D 맵으로 표시하고, 팔레트에서 선택한 외형 프리셋으로 기존 타일 액터의 메시와 머티리얼을 교체한다.

런타임 미니맵의 표시·탐색 프로토콜과는 별도 시스템이다. 월드 XY 좌표를 2D로 대응시키는 방향만 같으며, 런타임 미니맵 데이터나 위젯은 사용하지 않는다. 런타임 미니맵 규칙은 [MinimapSystem.md](MinimapSystem.md)가 소유한다.

## 편집 대상

- 현재 에디터 월드의 `AStaticMeshActor`만 스캔한다.
- 월드 XY가 설정된 격자 크기와 원점에 정렬된 액터를 메시별로 묶고, 가장 많이 반복된 메시 묶음을 현재 레벨의 고정 바닥 영역으로 사용한다.
- 한 번 교체된 `LS.MapTile` 태그 액터는 원래 메시가 달라져도 같은 고정 바닥 영역에 계속 포함한다.
- 빈 셀에는 새 액터를 만들지 않는다. 칠하기는 스캔된 기존 바닥 액터의 메시만 교체한다.
- 실제 맵 작업은 원본 레벨이 아닌 복사한 레벨에서 수행한다.

## 팔레트와 2D 캔버스

`ULSMapTilePalette` DataAsset이 타일별 메시, 전체 머티리얼 슬롯, 표시 이름, 2D 미리보기 색을 소유한다. 도구에서 새 팔레트를 만들거나 기존 팔레트를 선택하고, 레벨에서 선택한 액터의 현재 메시와 유효 머티리얼 슬롯을 외형 프리셋으로 등록한다. 같은 메시를 사용해도 머티리얼 구성이 다르면 서로 다른 타일이다. 바닥 영역 탐색은 팔레트 등록 여부에 의존하지 않는다.

캔버스는 월드 `+X`를 오른쪽, `+Y`를 위쪽으로 표시한다. 팔레트 타일과 월드 Yaw 회전값을 고른 뒤 좌클릭 또는 드래그하면 해당 셀의 메시, 전체 머티리얼 슬롯, Yaw를 교체한다. 캔버스에 마우스를 올리고 `R`을 누르면 선택 타일을 시계 방향으로 90도 회전한다. `Alt+좌클릭`은 메시와 머티리얼 구성이 모두 일치하는 타일을 팔레트에서 다시 선택하고 해당 셀의 Yaw도 가져온다. 마우스 휠과 가운데 버튼 드래그는 확대·축소와 이동에 사용한다.

칠하기 도구는 두 가지다. `한 칸 브러시`는 클릭한 셀을 바꾸고, 버튼을 누른 채 빠르게 이동해도 이전 셀과 현재 셀 사이를 보간해 지나간 타일을 빠짐없이 연속으로 칠한다. `직사각형`은 드래그 시작·끝 셀 사이를 파란 외곽선으로 표시하고 마우스 버튼을 놓을 때 범위 안의 기존 셀을 한 번에 칠한다. 두 도구 모두 한 번의 드래그를 하나의 Undo 트랜잭션으로 처리한다. `선택 위치에 뷰포트 고정 (탑뷰)`을 켜면 브러시는 현재 셀, 직사각형은 드래그 중인 범위의 중심을 에디터 레벨 뷰포트가 위에서 따라간다. 단순 호버에는 카메라가 움직이지 않는다.

미니맵 셀은 단색이나 머티리얼 에셋 자체의 기본 썸네일을 표시하지 않는다. 팔레트 항목마다 등록된 Plane 메시를 메모리에서만 임시 복제하고 전체 머티리얼 슬롯을 적용한 뒤, 그 조합을 수직 탑뷰 카메라로 렌더링해 표시한다. 카메라는 Plane의 XY 바운드를 기준으로 정사각형 프레임에 맞추고, UE 오빗 카메라의 기본 축과 월드 탑뷰 사이의 180도 차이를 카메라 기준 Yaw에서 보정한다. 원본 메시·머티리얼·레벨 액터는 수정하지 않으며 모든 셀은 팔레트별 캐시 이미지를 공유한다. 셀 Yaw에 맞춰 썸네일도 회전하고, 썸네일이 없거나 팔레트와 매칭되지 않는 셀은 기존 미리보기 색상을 대체 표시로 사용한다. 셀 사이의 어두운 선과 노란 호버·파란 직사각형 외곽선은 이미지 위에서도 유지한다. 확대하거나 이동한 타일은 미니맵 패널 영역 밖에서 그리지 않는다.

미니맵 왼쪽 위를 `(1, 1)`로 삼고 상단에는 열 번호, 왼쪽에는 행 번호를 `1~31`로 표시한다. 실제 맵 방향에 맞춰 작은 월드 Y 셀을 화면 위쪽, 큰 월드 Y 셀을 아래쪽에 배치한다. 눈금 띠는 타일 영역과 분리되며 확대하거나 이동해도 현재 화면에 보이는 셀 번호를 미니맵 가장자리에 유지한다. 호버한 셀의 행·열 번호는 노란색으로 강조한다. 축소해서 숫자가 겹칠 때는 표시 간격을 자동 조절하고 첫 번호와 마지막 번호는 유지한다.

팔레트 타일을 선택한 상태에서 미니맵 셀을 호버하면 해당 셀의 현재 이미지를 선택 타일의 탑뷰 썸네일로 임시 대체한다. 미니맵 호버 미리보기에는 현재 배치 Yaw가 적용되며, 반전된 미니맵 Y축을 기준으로 실제 액터와 같은 회전 방향을 사용한다. 클릭하기 전에는 레벨 액터와 타일 데이터가 바뀌지 않고, 호버가 끝나면 원래 타일 이미지로 돌아온다.

캔버스 셀에 마우스를 올리면 대응하는 월드 바닥 위치에 노란 박스를 표시한다. 팔레트 타일이 선택된 상태에서는 같은 위치에 저장·충돌·그림자 처리가 없는 임시 컴포넌트를 겹쳐 메시, 머티리얼, Yaw, 윗면 정렬 결과를 클릭 전에 미리 보여준다. 호버가 끝나거나 도구가 닫히면 임시 컴포넌트를 제거한다.

## 교체와 안전장치

- 드래그 한 번의 모든 교체는 하나의 에디터 트랜잭션으로 묶여 `Ctrl+Z`로 되돌릴 수 있다.
- 액터의 XY 위치, Pitch/Roll, 스케일은 유지하고 Yaw는 도구의 회전값으로 설정한다.
- 머티리얼 배열이 비어 있는 이전 팔레트 항목은 해당 메시의 기본 머티리얼 프리셋으로 취급한다.
- 윗면 높이 유지 옵션을 켜면 교체 전후 메시 바운드를 비교해 액터 Z만 보정한다. 따라서 메시 두께나 피벗 높이가 달라도 걸어 다니는 바닥 윗면을 맞출 수 있다.
- 교체된 액터에는 `LS.MapTile` 태그를 추가해 이후 팔레트 구성이 바뀌어도 다시 스캔할 수 있게 한다.
- 레벨 변경 후에는 `현재 레벨 새로고침`으로 편집 대상을 다시 수집한다.

## 진입 경로

에디터의 `Tools > LostSignal > 맵 타일 편집기`에서 연다. 팔레트와 레벨은 각각 별도 에셋이므로 변경 후 둘 다 저장해야 한다.
